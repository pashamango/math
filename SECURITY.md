# Security policy

This repository stores mathematical research and proofs, not application secrets. Never commit private keys, tokens, signing keys, credentials, undisclosed personal information, or executable hooks with unreviewed effects.

Report a suspected security issue privately using GitHub's **Report a vulnerability** or the repository's private security advisory feature, if enabled. Do not post exploitation details in a public issue.

For ordinary correctness problems (missing hypotheses, proof holes, unsound axioms, licensing mistakes), open a normal issue after checking whether public disclosure would introduce security or privacy risks. No SLA or public security contact is promised until maintainers establish one.
