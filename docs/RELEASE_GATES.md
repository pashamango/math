# Release gates

A public repository may contain unreleased research. A passing CI run does not by itself approve every interpretive or licensing claim.

- **Claims:** exact hypotheses and source signatures; distinguish imported results, definitions, models, counterexamples and interpretation.
- **Verification:** pinned dependencies and toolchain; fresh local package compilation; complete axiom audit; tested rejection gates; per-module kernel replay; inspected artifacts with source/check-out digests.
- **Review:** separate mathematical review with identity, scope and immutable source anchor; no fabricated human review.
- **Rights:** original code MIT; preserve third-party authorship and rights; no blanket relabeling of adapted material.
- **Release:** all relevant gates closed, explicit publication authorization, reviewed merge, green main CI, package-specific version tag and immutable evidence. Read back tag and release metadata before reporting completion.
